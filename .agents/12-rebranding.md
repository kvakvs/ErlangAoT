# We're Rebranding!

Search entire source tree and documents for ErlangAoT, and erlang_aot, not just
in text files, but also in sources, in headers, in tests, in CMake scripts.
Also visit documentation and README's everywhere searching for it.

## The New Name

- The short name: clause
- The namespace will be: clause
- The executable target name for the compiler will be: clau
- The prefix for ABI symbols will be: CLAUSE_
- Short ABI symbols prefix: eav1 becomes clausev1

## The Connotation and Motivation of the new Name

Same language. Different runtime. An escape clause.
- Clau — The escape clause for Erlang (meaning: Escape from BEAM dependency)
- Clau — A different way to run Erlang (meaning: Straightforward and approachable)

That combines the very short executable clau, existing clau.se domain, and the
idea of an alternative native execution environment without positioning the
project as an OTP replacement.

Escape Clause — not escaping Erlang, but escaping the assumption that Erlang must
always execute on BEAM.
